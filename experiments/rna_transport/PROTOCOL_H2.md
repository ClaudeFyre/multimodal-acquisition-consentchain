# H2 预注册协议：RNA + 临床模型的跨机构、跨平台可迁移性

版本 1.0 · 起草 2026-10-06 · 由 `freeze_protocol.py` 冻结（写入时间戳和 SHA-256）。
上位文件：`docs/RESEARCH_SCOPE_2026-10-06.md`（研究问题 H2）。

**冻结时的数据状态**：GEO 队列只读取过样本注释，用于统计可评估例数和事件**总数**
（`discovery/geo/geo_lung_os_screen.csv`），以及协变量的字段格式。**未下载任何表达数据，
未把任何结局与协变量或表达量做过关联分析。**开发队列（TCGA + CPTAC）此前已在内部分析中使用。

## 1. 问题与假设

在 TCGA + CPTAC 上开发的"RNA + 临床"Cox 模型，在独立机构的芯片队列中，
是否比只用临床变量（**包含病理分期**）的 Cox 模型有更好的 3 年生存区分度。

- **H2-primary**：合并的 ΔC（RNA+临床 − 临床，3 年 IPCW C-index）> 0，且 95% 置信区间不含 0。
- 区间含 0 → 结论为"跨平台外部队列中没有证据表明 RNA 在分期之外提供增量"，照样报告。
- 不允许根据外部结果修改任何模型、特征、阈值或纳入规则。

## 4. 基因映射与归一化（在看到任何结局前固定）

1. GDC 基因 ID 去掉版本号；以 GDC 文件中的 `gene_name`（GENCODE v36）作为符号。
2. 芯片探针 → 基因符号：使用 GEO 平台注释中的 Gene Symbol 字段；**一个探针对应多个基因的探针丢弃**；只接受符号完全一致的匹配（不做别名替换），覆盖率逐平台报告。
3. 一个基因有多个探针时，在**该队列内**取平均表达最高的探针（无监督、与结局无关）。
4. **公共基因集** = 开发 RNA 与全部 7 个外部平台都有的基因。
5. **样本内归一化**：每个样本在公共基因集上做秩变换并缩放到 [0, 1]（平均秩处理并列）。
   这使 TPM、MAS5、RMA、Illumina 等不同尺度和对数与否的数据可比。
6. 敏感性分析：分位数归一化到开发队列的参考分布（参考分布只由开发队列计算）。

## 5. 模型（与 `protocol_v2` 的经典分支一致）

- **临床 Cox**：§3 变量独热编码，`CoxPHSurvivalAnalysis(ties="breslow")`，α ∈ {1, 10, 100}。
- **RNA + 临床 Cox**：在临床变量基础上，加入 RNA 块：公共基因上按方差取前 256 个 → 标准化 → PCA 16 维。
- α 选择：开发队列内部，以 `random_state = 20261006` 按（来源 × 事件）分层随机留出 20% 作为验证集，取 Harrell C 最高的 α；然后用该 α 在**全部开发队列**上重新拟合（含基因筛选、标准化、PCA），得到唯一一个冻结模型应用于所有外部队列。
- 同一流程另做开发队列 5 折交叉验证（`random_state = 20261004`，与 v2 相同），仅作内部参考。

## 6. 评估

每个外部队列单独评估：

- **主指标**：3 年 IPCW C-index，τ = min(1095 天, 该队列可估支持)；删失分布由**目标队列自身**的 Kaplan–Meier 估计。
- **ΔC** = C(RNA+临床) − C(临床)，按患者 bootstrap 2,000 次，配对重采样，取百分位 95% 区间。
- 次要指标：Harrell C；1、2、3 年时间依赖 AUC；校准斜率（在目标队列中以线性预测值为唯一协变量的 Cox 回归系数）；3 年的预测平均生存概率与 KM 观测值之差。

**合并**：以 bootstrap 方差为权重，对各队列 ΔC 做 DerSimonian–Laird 随机效应合并；报告 τ² 和 I²。

## 7. 预设的次要与敏感性分析（不改变主结论的判定）

1. 不含分期的临床基线（年龄、性别、组织学），与 H1 内部协议对齐。
2. 仅腺癌子集（5 个队列只有或主要是腺癌）。
3. 开发与外部都限制为 I–III 期。
4. 作者预处理的 RNA 特征（MMIST）代替 GDC TPM。
5. PCA 32 维代替 16 维。
6. 分位数归一化代替秩归一化。
7. 只有在 GSE41271 的时间单位能从文档确定时，才纳入它。

## 8. 已知限制（预先声明）

- 外部队列多为手术切除的早中期病例，开发队列包括各期，人群不同。
- 芯片与 RNA-seq 的差异只能部分通过秩归一化消除。
- 各队列分期版本（AJCC 6/7 版）不一，只做到分期组的粒度。
- 只验证 RNA 分支，不能代替 WSI 分支或三模态整体的外部确认。
- 生存起点在各队列中均为手术或诊断时间，定义不完全一致。
