# H2 结果：RNA + 临床模型的跨机构、跨平台可迁移性

运行日期 2026-10-06。协议 `PROTOCOL_H2.md`（冻结于 2026-10-06T09:38Z，SHA-256 01049de6…）；
实现偏差见 `DEVIATIONS.md`（#1–7，全部在接触结局之前）。原始结果：`results/*.json`；日志：`run_h2.log`、`run_h2_s456.log`。

## 数据

- **开发队列**：TCGA + CPTAC NSCLC，1,293 例（分期完整），476 个死亡事件。RNA 来自 GDC STAR-Counts TPM，全部文件经 MD5 校验。
- **外部队列**：7 个 GEO 芯片队列，主分析 1,690 例、718 个事件；4 种平台（GPL570、GPL96、GPL6884、GPL15048）。
- **公共基因**：10,902 个（开发队列与 7 个平台的交集）；按样本内秩归一化。
- 选定的 Cox 惩罚系数：临床模型 α = 10，RNA + 临床模型 α = 1。一个冻结模型原样应用于全部外部队列。

## 主结果（预设判定）

## 解读

1. **RNA 的外部"增益"大部分来自分期信息。**与不含分期的临床基线比，增益为 +0.073（显著）；加入分期后降到 +0.022（边缘）。约 70% 的表观增益在临床模型知道分期后消失。
2. **这直接影响 H1 的解读。**内部 H1 的 +0.071 是相对**不含分期**的临床基线得出的；外部 S1 的 +0.073 几乎与之相同。这提示内部"融合优于临床"的结论，很大程度上可能反映的是模态特征携带了分期信息，而不是分期之外的生物学信息。**需要在内部用含分期的临床基线复核 H1**（见下一步）。
3. **跨平台迁移本身没有崩溃**：TCGA RNA-seq 上训练的模型，在 4 种芯片平台上都保持了与临床模型相当或更高的区分度，S6 换归一化方法结果不变。RNA 分支"可迁移但增量小"。
4. **校准不可迁移**：外部校准斜率多数 > 1（风险分数被压缩），3 年预测生存与 KM 观测值的偏差在不同队列中方向不一（例如 GSE31210 预测 0.80、观测 0.92；GSE37745 预测 0.72、观测 0.57）。在新机构使用前需要重新校准。

## 局限（预先声明 + 新发现）

- 外部队列以手术切除的早中期腺癌为主，开发队列各期、各组织学都有。
- 只验证了 RNA 分支，不能代替 WSI 分支或三模态整体的外部确认。
- 分期是术后病理分期：本分析的预测时点是"术后"，不是"诊断时"。
- 时间依赖 AUC 的 3 年时间点因实现边界条件（只纳入严格小于 τ = 1095 天的时间点）未能计算，有待补算；不影响主指标。
- 各外部队列之间的人群与治疗差异（如辅助化疗比例）未做调整，只通过随机效应合并吸收。

## 下一步建议

1. **在内部复核 H1**：用含病理分期的临床基线重做"融合 vs 临床"比较（数据已在本地，不需要新下载）。如果内部增益同样大幅缩小，论文主张需要从"融合优于临床"改为"融合在分期之外的增量很小，且主要来源是 X"。
2. 补算 3 年时间依赖 AUC。
3. H3（WSI 分支）的价值需要据此重新评估：同样必须以含分期的临床模型为基线。
