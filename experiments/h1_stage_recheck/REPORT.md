# H1 复核结果：加入病理分期后，内部融合增益基本消失

运行于 2026-10-07T00:36Z。计划见 `ADDENDUM.md`（运行前冻结，SHA-256 f4a809ad…，记录于 `ADDENDUM.freeze.txt`）。
性质：**事后探索性分析**（由 H2 结果触发）。原始输出：`results.json`、`per_fold.csv`、`recheck.log`。

## 1. 复现核对

按 v2 `ipcw_bootstrap.py` 的写法，复算得到早期融合 − 临床 Cox = **+0.0711**，与 v2 报告值逐位一致，
说明本次使用的队列、折分、预处理和模型与 v2 完全相同。

## 2. 发现 v2 的 IPCW C-index 实现偏离标准定义

v2 的 `ipcw_bootstrap.py` 在计算 3 年 IPCW C-index 前，先删除了所有时间 ≥ 1095 天的测试患者
（`pred.time_days < TAU`）。标准 Uno 估计量（scikit-survival `concordance_index_ipcw`）只是让这些患者
**不作为先发生事件的一方**，但仍保留他们作为比较对象。v2 的写法因此丢掉了"长期生存者"这一最有信息量的比较组。

| 版本 A（不含分期） | 临床 C | 融合 C | ΔC [95% CI] |
|---|---:|---:|---|
| v2 写法 | 0.518 | 0.589 | +0.071 [+0.031, +0.108] |
| **标准 Uno** | 0.580 | 0.622 | **+0.042 [+0.008, +0.077]**，p = 0.012 |

v2 跟进报告中"临床 Cox 0.5800"一栏与标准 Uno 一致，而 +0.0711 这个差值来自 v2 写法——两者混用了不同的估计量。
**H1 的正确数值应为 +0.042**：在不含分期的设定下，增益仍然存在，但比原报告小约 40%。

## 3. 主结果：加入分期

| 临床基线 | 临床 C | 融合 C | ΔC（标准 Uno）[95% CI] | p |
|---|---:|---:|---|---:|
| A 不含分期（v2 诊断时设定） | 0.580 | 0.622 | +0.042 [+0.008, +0.077] | 0.012 |
| **B + 病理分期组 I–IV（主）** | 0.644 | 0.645 | **+0.001 [−0.024, +0.029]** | 0.96 |
| C + v2 预设的 `stage_enhanced`（T/N/M/分期/版本） | 0.652 | 0.656 | +0.004 [−0.019, +0.029] | 0.71 |

缩小比例 (Δ_A − Δ_B) / Δ_A = **97%**。按 v2 写法计算，B 为 +0.022 [−0.007, +0.051]，结论相同（区间含 0）。

## 4. 与 H2 的对照

| | 不含分期 | 含分期 |
|---|---|---|
| 内部（WSI + RNA + 临床，本复核） | +0.042 [+0.008, +0.077] | +0.001 [−0.024, +0.029] |
| 外部（RNA + 临床，H2，7 个 GEO 队列） | +0.073 [+0.043, +0.103] | +0.022 [−0.001, +0.045] |

内部和外部讲的是同一件事：**多模态特征的生存区分度增益，基本上是病理分期信息的替代**。
临床模型一旦包含分期，内部增益归零，外部增益只剩下统计上不确定的 +0.02。

## 5. 对研究主张的影响

1. "融合优于临床基线"只在**不含分期**的基线下成立；这在术后场景下不是公平的比较，因为病理分期在术后总是可得的。
2. "诊断时"设定也站不住：TCGA/CPTAC 的 WSI 和 RNA 本身就来自手术切除标本，诊断时同样不可得。
   因此 v2 的"诊断时 estimand"与所用特征在时间上并不一致——这正是审计中列为阻塞项的"采集时间顺序"问题，现在有了定量后果。
3. 建议把论文主张改写为一项**评测与警示研究**：
   - 在 NSCLC 生存预测中，常见的"多模态融合优于临床"结果对基线选择高度敏感，排除病理分期会把分期信息误记为模态增益；
   - 一处常见的 IPCW C-index 实现偏差会把增益进一步夸大约 70%（+0.042 → +0.071）；
   - 跨 7 个外部队列、4 种芯片平台的验证给出一致结论。
4. WSI 分支（H3）的价值同样要以含分期的基线衡量；在内部已经归零的情况下，为 H3 申请 NLST 数据的优先级应下调。

## 6. 局限

- 只比较了经典 Cox 早期融合；神经网络和后期融合未复核（v2 结果显示它们与早期融合相近）。
