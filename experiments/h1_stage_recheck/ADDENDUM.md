# H1 复核附录：加入病理分期后，内部融合增益还剩多少

写于 2026-10-07，**运行之前**。性质：**事后（post-hoc）探索性分析**，由 H2 结果触发
（外部 RNA 增益在不含分期时 +0.073，含分期后降到 +0.022，见 `experiments/rna_transport/REPORT_H2.md`）。
本分析不改变 `protocol_v2` 的任何冻结结论，结果单独报告并标注为事后分析。

## 问题

内部开发队列上，早期融合 Cox（临床 + WSI + RNA）相对临床 Cox 的 3 年 IPCW C-index 增益，
在临床模型加入病理分期后是否大幅缩小。

**预测时点的变化**：`protocol_v2` 按"诊断时"预测，故排除了术后病理分期。加入病理分期后，
预测时点变为"**术后**"。这是一个不同的、同样有临床意义的问题，报告时分开命名。

## 设计（尽量复用 v2）

- 同一队列（1,313 例）、同一外层 5 折（`StratifiedKFold`，`random_state = 20261004`，按来源 × 事件分层）、
  同一内层验证（20%，`random_state = 101 + fold`）、同一预处理（`models.Preprocessor`：方差前 256 → 标准化 → PCA 16）、
  同一 Cox 拟合（`models.fit_cox`，α ∈ {1, 10, 100}，按内层验证 Harrell C 选择）。
  经典 Cox 模型是确定性的，因此每折只拟合一次（v2 的 3 个种子只影响神经网络）。
- 临床变量的三种版本：
  - **A**：v2 基线（不含分期），用于复现 v2 结果；
  - **B（主）**：A + 病理分期组 I–IV（由 GDC 原始 JSON 重建，与 H2 相同规则；缺失作为单独类别）；
  - **C（敏感性）**：A + v2 协议预先列出的 `stage_enhanced` 5 列（作者编码的 T、N、M、分期、版本）。
- 每个版本拟合"临床 Cox"和"早期融合 Cox"（v2 的 `full_x`：临床块 + WSI 块 + RNA 块 + 模态存在指示）。

## 指标

- **主**：3 年 IPCW C-index，scikit-survival `concordance_index_ipcw(tau = 1095)`，删失分布用外层训练集估计
  （标准 Uno 估计量：时间 ≥ τ 的患者保留为比较对象）。
- **复现用**：v2 `ipcw_bootstrap.py` 的写法（先删去时间 ≥ τ 的测试患者再计算）。
  **注意：该写法与标准 Uno 估计量不同，长期生存者不再作为比较对象**；仅用于确认能复现 v2 的 +0.0711。
- 配对 bootstrap：每折内对测试患者重采样 2,000 次（`seed = 20261007`），两个模型共用同一重采样；各折差值取平均后求百分位区间。

## 解读规则（事先写定）

- 报告 Δ_A（复现）、Δ_B（主）、Δ_C，以及缩小比例 (Δ_A − Δ_B) / Δ_A。
- 若 Δ_B 的区间含 0：内部同样没有证据表明融合在分期之外有增量，与 H2 一致。
- 若 Δ_B 区间不含 0：融合在分期之外仍有内部增量，但外部（H2，仅 RNA 分支）未能确认。
- 无论结果如何，都不回头修改 v2 或 H2 的任何设定。
