# B1 冻结协议：按成本逐步采集模态的 NSCLC 术后生存预测

写于 2026-10-08，**任何 B1 分析运行之前**。冻结方式：本文件的 SHA-256 记录在 `PROTOCOL_B1.freeze.json`，之后的任何偏离写入 `DEVIATIONS.md`，不修改本文件。

## 0. 运行前已知的信息（如实披露）

- 开发队列（1,313 例，TCGA + CPTAC）与 H1 复核**完全相同**，外层 5 折、预处理和 Cox 拟合也完全相同。H1 已经给出两种**静态**策略的结果：在含分期的临床基线（版本 B）下，"全部采集 WSI + RNA"的早期融合 Cox 相对临床 Cox 的 3 年 Uno C-index 差为 +0.001 [−0.024, +0.029]。
- 因此本协议**不是**对"融合是否有增益"的确认性检验。B1 的新内容是**逐例采集策略、成本–性能前沿和 RNA-seq 决策规则**，这些都没有运行过。
- 本机 GPU 被其他实验占用；B1 全部为 CPU 计算。

## 1. 研究问题

在术后预后设定下，按"临床病理（含病理分期）→ + H&E WSI → + RNA-seq"的阶梯，为每位患者决定是否追加下一个模态：

- **Q1（主）**：在已有临床病理 + WSI 的前提下，需要为多大比例的患者做 RNA-seq，3 年 C-index 才能相对"全部做 RNA-seq"保持非劣？
- **Q2**：基于信息价值（VoI）的逐例选择，是否优于相同预算下的随机选择？
- **Q3**：成本–性能 Pareto 前沿（WSI 预算 × RNA 预算），在多种成本比例下的形状。
- **Q4（对照）**：在**不含分期**的临床基线（版本 A，对应缺少完整分期的场景）下重复 Q1–Q3，检验前沿是否依赖基线。

## 2. 数据与预测时点

- 队列：`experiments/lung_missingness/prepared/`（cohort.csv、features.npz、summary.json），只读。
- 终点：总生存，截断 τ = 1095 天。
- 预测时点：**术后**（WSI 和 RNA 均来自手术标本，病理分期术后可得）。
- 临床变量：与 H1 相同的版本 B（v2 基线临床列去掉 AJCC 分期相关列 + 病理分期组 I–IV，由 GDC 原始 JSON 按 H2 规则重建，缺失为单独类别）；版本 A 为不含分期的对照。
- CT / PET：仅 68 / 30 例有特征，**不纳入**阶梯，只在局限性中说明。
- 外部 GEO 队列：只有 RNA + 临床，不在本次运行中；如需外部验证，另写附录协议。

## 3. 模型（每个外层折内只用训练数据拟合）

- 折分：`StratifiedKFold(5, shuffle=True, random_state=20261004)`，按"来源 × 事件"分层；内层验证 20%，`random_state = 101 + fold`（与 H1 相同）。
- 预处理：`models.Preprocessor`（WSI、RNA 各取方差前 256 → 标准化 → PCA 16）。
- 三个 Cox 模型（`models.fit_cox`，α ∈ {1, 10, 100}，按内层验证 Harrell C 选择）：
  - f_C：临床块；
  - f_CW：临床块 + WSI 块 + WSI 存在指示；
  - f_CWR：临床块 + WSI 块 + RNA 块 + 两个存在指示（即 H1 的早期融合）。
- 公共风险尺度：每个模型的 3 年事件概率 r = 1 − S(τ | x)（Cox 拟合的 Breslow 生存函数），使不同模态级别的患者可以在同一排序中比较。
- 若患者实际缺少某个模态（WSI 3 例、RNA 8 例），该模态视为"已采集但无信息"，按模型的存在指示处理（与 H1 一致）。

## 4. 采集策略

记 b_W、b_R 为 WSI、RNA 的采集比例（预算），网格 {0, 0.1, …, 1.0}，且 b_R ≤ b_W（RNA 只在已做 WSI 的患者中选择）。患者最终风险 = 其最高采集级别对应模型的 r。

- **VoI 策略（主）**：
  - 目标量：模态带来的风险变化幅度。WSI 步：d_W = |r_CW − r_C|；RNA 步：d_R = |r_CWR − r_CW|。
  - 训练目标在训练集内用**内层 5 折交叉拟合**得到（三个 Cox 模型在内层折上重拟合，对留出部分预测），避免训练集上的过拟合低估。
  - VoI 回归器：`HistGradientBoostingRegressor(max_depth=3, learning_rate=0.05, max_iter=200, random_state=0)`。WSI 步输入 = 临床块；RNA 步输入 = 临床块 + WSI 块 + WSI 存在指示。
  - 测试集上按预测的 d 从高到低选取前 b 比例的患者采集。
- **随机策略（对照）**：同预算下随机选择，每折重复 100 次取平均。
- **静态策略**：无（b = 0）和全部（b = 1）。
- **神谕策略（仅作上界展示）**：用测试集上真实的 d 排序，不参与任何结论。

## 5. 指标与统计

- **主指标**：3 年 Uno IPCW C-index（`sksurv.metrics.concordance_index_ipcw`，tau = 1095，删失分布用外层训练集估计；标准 Uno，不删除时间 ≥ τ 的患者）。各折取平均。
- 次要指标：3 年累积/动态 AUC（`cumulative_dynamic_auc`，时间点 1095）；3 年 IPCW Brier（`brier_score`）。
- **非劣界值 δ = 0.01**（C-index）。
- **Q1 主分析**（b_W = 1，b_R ∈ 网格）：对每个 b_R 计算 C(policy) − C(全部 RNA)，配对 bootstrap（每折测试患者重采样 2,000 次，`seed = 20261008`，所有策略共用同一组重采样，各折差值取平均后求 2.5%/97.5% 分位）。**最小非劣预算** b_R* = 满足 95% 区间下限 > −δ 的最小 b_R。
- **Q2**：在 b_R ∈ {0.1, 0.2, 0.3, 0.5} 上比较 VoI 与随机（随机策略在每次 bootstrap 中用其 100 次重复的平均 C）。对 4 个比较做 Holm 校正。
- **Q3**：完整 66 点网格的点估计；Pareto 前沿按成本场景计算（bootstrap 500 次给出前沿上各点的区间，仅描述性）。
- **Q4**：在版本 A 上重复 Q1–Q3，作为对照，描述性报告。

## 6. 成本向量

真实费用、周转时间和碳排放要在写论文时**引用文献**，本协议不使用任何未查证的数值。计算中统一用**相对单位**：临床病理 = 0（标准流程已包含），WSI = 1，RNA-seq = κ。预设 κ ∈ {2, 5, 10, 20, 50}，主场景 κ = 10。由于前沿首先按"采集比例"给出，换算到任何成本场景都不需要重跑模型。周转时间和碳排放在拿到文献数值后，按同样方法换算。

## 7. RNA-seq 决策规则

- 在每个外层训练集上，把 VoI 策略在 b_R* 处的选择（被选中 = 1）作为标签，拟合深度 ≤ 2 的决策树（`DecisionTreeClassifier(max_depth=2, min_samples_leaf=30, random_state=0)`），输入为**可解释的原始临床变量**（分期组、组织学、年龄组、吸烟状态）加 WSI 块的第 1 主成分。报告 5 折中出现的规则及其稳定性。
- 若 b_R* = 0（即不需要 RNA-seq 也非劣），则不拟合规则，直接报告"该队列中没有一个患者亚群需要 RNA-seq"，并给出事先指定的亚组描述：分期 I vs II–IV、LUAD vs LUSC 中 C(CWR) − C(CW) 的点估计和区间（探索性）。

## 8. 解读规则（事先写定）

- b_R* ≤ 0.3：报告"按 VoI 只需为 ≤ 30% 的患者做 RNA-seq 即可非劣"。
- b_R* = 0：报告"在含分期的术后设定下，RNA-seq 不带来可检测的区分度收益"，这本身就是论文的主要发现，不得为了得到非零预算而改动界值、模型或指标。
- 若 VoI 不优于随机：如实报告；说明逐例选择没有带来额外收益，前沿主要由静态策略决定。
- 版本 A 的前沿与版本 B 不同时，表述为"采集策略的价值依赖于临床基线是否包含分期"。

- 不改动 v2、H1、H2 的任何文件或结论。
- 不在测试集上选择任何超参数、界值或预算网格。
- 区块链（A2）相关实验不在本机进行。
