# 后续分析补充：配对 IPCW、神经网络网格、校准与迁移

日期：2026-10-04。所有新增产物均位于新 `runs/` 子目录和 `results_v2_final/`；首轮结果目录和原始数据未覆盖。本补充不改变“回顾性技术分析、尚无独立确认性验证”的研究定位。本地盘点发现 TCIA NSCLC-Radiomics 与 NSCLC-Radiogenomics 两个候选；其证据、限制和适用边界见 `RESEARCH_DECISION_AND_NEXT_STEPS.md`。它们尚未建立为当前 WSI+RNA 融合的确认队列。

## 1. IPCW 患者配对 bootstrap

对冻结五折、每折三种子，按折拟合训练删失分布；测试患者在同折模型和训练种子间使用共同 bootstrap 重采样。C-index按折计算后汇总，没有跨折合并未校准风险。实现和 scikit-survival 的 `concordance_index_ipcw` 单折数值差约 `1.6×10^-6`。

- 早期融合 Cox 对临床 Cox，自然条件：三年 IPCW C-index 差 `+0.0711`，95% 配对区间 `[0.0340, 0.1101]`，Holm 校正 p=`0.0030`。
- 网格选出的随机丢弃 TokenCox 对同架构 masked TokenCox，自然条件安全性比较：差 `+0.0060`，95% 区间 `[-0.0041, 0.0168]`。
- 对随机删除率 `0.1/0.3/0.5/0.7/0.9` 等权平均：差 `+0.0115`，95% 区间 `[-0.0008, 0.0242]`，Holm 校正 p=`0.0675`。点估计超过项目的 `0.01` 门槛，但区间仍覆盖零，未达到“校正区间支持改善”的继续门槛。

这组区间条件于已拟合模型，不含重训练不确定性；患者配对 bootstrap 文件为 `results_v2_final/primary_ipcw_comparisons.csv` 和 `results_v2_final/tuned_dropout_ipcw_comparisons.csv`。

## 2. MLP-Cox 与预定超参网格

训练五折 × 三种子，每折每种子 20 个候选（总计 300 个）：MLP-Cox 与 masked TokenCox 各 4 种学习率/weight decay 组合；随机丢弃 TokenCox 为上述 4 组合 × 丢弃率 `0.1/0.3/0.5`。所有候选最多 300 epoch、每 5 epoch 验证、patience 30。最终配置按每折三种子内层验证 Harrell C 均值选择，不查看测试结果。每个候选的验证分数、训练检查点和选中配置均保留于 `runs/neural_grid_v2_retry1/`。

| 模型族 | 自然条件 3 年 IPCW C | 1/2/3 年 AUC | 1/2/3 年 Brier | 支持区间 IBS |
|---|---:|---|---|---:|
| 临床 Cox（既有冻结基线） | 0.5800 | 0.5801 / — / — | 0.1133 / — / — | — |
| 后期融合 Cox（既有冻结基线） | 0.6398 | 既有流程仅评估 1 年 | 0.1088 / — / — | — |
| MLP-Cox（网格内选参） | 0.6117 | 0.6469 / 0.6521 / 0.6356 | 0.1107 / 0.1797 / 0.2271 | 0.1743 |
| masked TokenCox（网格内选参） | 0.6231 | 0.6599 / 0.6596 / 0.6499 | 0.1145 / 0.1862 / 0.2321 | 0.1797 |
| 随机丢弃 TokenCox（网格内选参） | 0.6373 | 0.6694 / 0.6775 / 0.6712 | 0.1120 / 0.1787 / 0.2212 | 0.1726 |

表中网格模型均为外折指标的折/种子均值。随机丢弃模型接近后期融合，但 IPCW C-index 均值未高于后期融合，也未达到可靠缺失增益门槛。所有三年时间点须以各外折训练删失支持为准；逐运行指标保留了不可估计原因。

## 3. 多时点校准

每个外折的生存概率使用训练集风险分数拟合的一维 Cox 校准器生成；验证/测试结局不拟合校准参数。五折测试预测按患者平均三个训练种子后分箱，IPCW 估计观测生存率：

| 模型 | 年 | 平均预测生存 | IPCW 观测生存 |
|---|---:|---:|---:|
| MLP-Cox | 1 | 0.8764 | 0.8698 |
| MLP-Cox | 2 | 0.7488 | 0.7450 |
| MLP-Cox | 3 | 0.6313 | 0.6242 |
| masked TokenCox | 1 / 2 / 3 | 0.8772 / 0.7503 / 0.6338 | 0.8700 / 0.7453 / 0.6215 |
| 随机丢弃 TokenCox | 1 / 2 / 3 | 0.8768 / 0.7494 / 0.6313 | 0.8706 / 0.7444 / 0.6238 |

完整分箱数据在 `results_v2_final/calibration_points.csv`，图在 `calibration_curves.png`。总体均值接近不等于每个分箱均校准；曲线没有加入置信带。Brier 与 integrated Brier 同时报告，避免只凭排序指标评价概率质量。

## 4. 双向迁移与失效压力

超参配置取自内部五折验证所选配置的众数，训练和概率校准仅用来源队列；两个迁移方向都没有用目标队列选择配置。

| 来源 → 目标 | MLP-Cox | masked TokenCox | 随机丢弃 TokenCox |
|---|---:|---:|---:|
| TCGA → CPTAC | 0.6224 | 0.6115 | 0.6559 |
| CPTAC → TCGA | 0.5386 | 0.5623 | 0.5632 |

数值为三年 IPCW C 均值，三种子重复使用同一目标队列，不代表三组独立外部验证。CPTAC 曾被前序探索使用，因此以上仍属探索性迁移。结果显示方向不对称，尤其较小 CPTAC 来源训练时性能较低。

自然、缺单模态、仅临床、0–90% 随机删除及患者内内容置换见网格指标。另对年龄 bin 和病理分期训练折中位数定义高低组，分别测试高组删除概率 0.8、低组 0.1，以及反向策略；WSI/RNA 单独删除，未用结局标签生成缺失。条件化结果在 `runs/conditional_stress_v2/metrics.csv`。这是人工机制压力测试，不能证明真实 MNAR 鲁棒性。分期只用于构造删除条件，不作为预测输入。

## 决策

后期融合仍是主基线。MLP-Cox 没有超过它。超参选择后的随机丢弃 TokenCox 与 masked 架构自然条件差异较小；在预定缺失率分布的 IPCW 增益点估计为 `0.0115`，但患者区间跨零且 Holm 校正 p=`0.0675`，不满足预设继续门槛。因此本轮结果不支持继续扩展方法创新分支；保留随机丢弃作为有竞争力的鲁棒性基线即可。融合相对临床 Cox 有统计支持，但这不等于后期融合优于其他融合模型。继续论文主张之前仍需确认采集时间顺序、冻结特征预处理来源并完成适配当前预测任务的独立验证。
